# CUC Habitat v0.2 Design

## Purpose

v0.2 turns the runnable v0.1 prototype into a more repeatable benchmark without expanding the agent ladder beyond Alpha-Epsilon.

## Deterministic episodes

Named fixtures define auditable starting conditions: quiet-world drift, misleading urgency, storage disorder, energy shortage, hidden maintenance opportunity, and overload with competing signals. A fixture always creates the same starting state. Seeds may then vary stochastic disturbances for robustness studies.

## Multi-seed evaluation

Evaluation should report mean score, variance, worst-decile mean, score range, and band distribution. Single-seed results remain examples rather than benchmark claims.

## Scoring improvements

v0.2 should prefer behavior observed during an episode over architecture-specific score priors. Domain scores must stay bounded in [0, 1], expose their assumptions, and be tested against deliberately strong and degraded trajectories.

## Perception

BrailleStream should become an optional constrained observation layer, including a reproducible noise/degradation setting. Raw-state access remains available for baseline comparisons.

## Out of scope

- Zeta, Omega, or Field-Coherent Agent implementation
- consciousness, sentience, personhood, or moral-status certification
- required external model APIs
- secret or committed API credentials
- claims that heuristic scores are scientifically validated

## Gate

Major new agent stages should wait until deterministic episodes, multi-seed reporting, result schemas, and CI checks are stable.
